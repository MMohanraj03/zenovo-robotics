# ⚡ Zenovo Robotics — Autonomous Commercial Robotics & AI

A cutting-edge, realistic commercial humanoid robotics platform website featuring high-definition 10-second bipedal action clips, realistic mechanical telemetry, interactive Web Audio FX, an AI command terminal, and a holographic lightbox video inspector.

---

## 🚀 Key Features

- **10-Second High-Speed Bipedal Action Sequence (`robot_action_10s.mp4`)**:
  - Phase 1: *Atlas-Dynamic* agile obstacle vault in test hangar B4
  - Phase 2: *Vision-Stereo* stereoscopic lens autofocus calibration
  - Phase 3: *Prime-One* whole-body Model Predictive Control (MPC) balance recovery
- **Dedicated 10s Video Archive for Every Robot Model**:
  - *Zenovo Robotic Atlas-Dynamic* (Bipedal Obstacle Course)
  - *Zenovo Robotic Kinetic-Legs* (Hydraulic Suspension & Stride)
  - *Zenovo Robotic Dexter-Grip* (16-DoF Tactile Articulated Hand)
  - *Zenovo Robotic Prime-One* (Factory Workstation Humanoid)
  - *Zenovo Robotic Vision-Stereo* (Dual Multi-Focal Optical Depth Lenses)
  - *Zenovo Robotic Cranium-X* (CNC Titanium Edge Computing Core)
  - *Zenovo Robotic Prime-X* (Flagship Biomechatronic Humanoid)
  - *Zenovo Robotic Sensor-Array* (360° LiDAR & Thermal Vision)
- **Interactive Cybernetic AI Command Terminal**:
  - Live command execution: `DIAGNOSE`, `OVERCLOCK`, `SCAN_SWARM`, `ACTION`, `STATUS`, and `CLEAR`
- **Dynamic Web Audio FX Synthesizer**:
  - Synthesized brushless DC electric servo whine, hydraulic valve hisses, and impact thuds
- **Holographic Lightbox Viewscreen**:
  - Frame-accurate video playback, timeline scrubber, and detailed engineering specifications

---

## 🛠️ Technology Stack

- **HTML5**: Semantic markup, HUD overlays, high-speed video players
- **Vanilla CSS**: Custom cyber design system, glassmorphic HUDs, scanline animations, responsive layout
- **Vanilla JavaScript**: Web Audio API, Canvas particle mesh, real-time telemetry engine, video controllers
- **FFmpeg**: H.264 High-Profile video rendering & AAC audio synthesis
